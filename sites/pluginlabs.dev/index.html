PluginLabs geliştirici belgeleri

Uygulamanı PluginLabs Hub'a bağla: kataloğu oku, kullanıcı onayıyla indirme başlat, MyMind'a metin gönder, diğer uygulamalarla kanallar üzerinden veri paylaş ve kendi işlevlerini sağlayıcı olarak kaydet.

Hızlı başlangıçİlk isteğini 5 dakikada gönder. API başvurusuTüm yollar, yöntemler ve izinler. Sağlayıcı SDKUygulamanın işlevlerini Hub'a aç.

Hızlı başlangıç

  1. PluginLabs Hub'ı getpluginlabs.com adresinden indirip aç.
  2. API ve izinler → İstemci oluştur ekranında uygulamana gereken izinleri seç. Anahtar (plh_…) yalnız bir kez gösterilir.
  3. Anahtarı işletim sisteminin kimlik bilgisi kasasına kaydet ve ortam değişkeni olarak ver.
  4. SDK'yı (sdk/client.cjs) projene kopyala ya da aynı HTTP sözleşmesini kendi dilinde uygula.
ilk-istek
const { PluginLabsClient } = require("./sdk/client.cjs");
const client = new PluginLabsClient({ token: process.env.PLUGINLABS_TOKEN });

// MyMind'a metin gönder (izin: mymind.chat)
const yanit = await client.chat([
  { role: "user", content: "Bu metni özetle: ..." },
]);
console.log(yanit.choices[0].message.content);
# Kataloğu oku (izin: catalog.read)
curl -s http://127.0.0.1:47632/v1/catalog \
  -H "Authorization: Bearer $PLUGINLABS_TOKEN"
import json, os, urllib.request

istek = urllib.request.Request(
    "http://127.0.0.1:47632/v1/chat/completions",
    data=json.dumps({"model": "mymind-lite", "max_tokens": 256,
                     "messages": [{"role": "user", "content": "Merhaba"}]}).encode(),
    headers={"Authorization": "Bearer " + os.environ["PLUGINLABS_TOKEN"],
             "Content-Type": "application/json"},
)
print(json.load(urllib.request.urlopen(istek, timeout=150)))

Kimlik doğrulama

Her istek Authorization: Bearer plh_… başlığı taşır. API yalnız literal 127.0.0.1 üzerinde, varsayılan 47632 portunda dinler; Host başlığı denetlenir.

Anahtarı tarayıcıya koyma
Origin başlığı taşıyan tarayıcı istekleri reddedilir. Anahtarı ön yüz JavaScript'ine, web sayfalarına ya da günlüklere yazma. Kaybolursa Hub'dan iptal edip yenisini üret.
  • Hub anahtarın yalnız SHA-256 özetini saklar.
  • HTTP API yönetici anahtarı oluşturamaz ve kendi isteğini onaylayamaz.
  • Tarayıcı eklentileri için tek istisna POST /v1/browser/sync'tir: browser.manage izinli, kayıtlı eklenti kimliğine bağlanmış anahtar gerekir.

Onay gerektiren istekler hemen bir istek kimliği döndürür; sonucu GET /v1/requests/:id ile izle. İstek kuyrukları bellektedir ve Hub yeniden başladığında kaybolur.

MyMind

Model adı her zaman mymind-lite'tır. Kullanıcı kendi GGUF modelini içe aktarsa bile istemcide değişiklik gerekmez. temperature 0–1 arasında iletilir; verilmezse 0,4 kullanılır.

Hazır görevler

POST /v1/mymind/run ile istem yazmadan doğrulanmış görevleri çalıştır. Kullanılabilir görevleri GET /v1/mymind/capabilities döndürür.

mymind-run.cjs
const { ready, tasks } = await client.mymind.capabilities();
if (ready) {
  const ozet = await client.mymind.run("summarize", { text: notMetni, sentences: 3 });
}

Arayüz kuralı
MyMind çıktısını kullanıcıya gösterirken her zaman MyMind rozetini ve kaynağını göster. Yalnız işin gerektirdiği metni gönder.

Kanallar ve canlı akış

Kanallar uygulamalar arası küçük, süreli veri köprüleridir. Ad biçimi <ad-alanı>.<kanal> (örn. leo-helper.son-kod); bir istemci yalnız kendi ad alanına yazar ve share ile en fazla 8 ad alanıyla paylaşır.

kanal.cjs
// Yayınla (channels.publish) — ttlSeconds: 5–86400, varsayılan 3600
await client.publish("ornek-uygulama.durum", { hazir: true }, { ttlSeconds: 600, share: ["mind-palace"] });

// Canlı dinle (channels.read) — dönen işlev akışı kapatır
const kapat = client.subscribe(["ornek-uygulama.durum"], (kayit) => console.log(kayit));

Sınırlar: kayıt başına 8.000 karakter, 6 derinlik, 40 anahtar; istemci başına 16, toplam 64 kanal; dakikada 30 yayın.

Sağlayıcı SDK

Uygulamanın işlevlerini Hub'a açmak için ProviderAgent kullan. Ajan 127.0.0.1 üzerinde rastgele bir portta callback sunucusu açar, Hub'ın challenge isteğini HMAC ile yanıtlar ve kaydını 30 saniyede bir yeniler (90 saniyelik kira).

saglayici.cjs
// İzinler: providers.register + actions.invoke
const { PluginLabsClient, ProviderAgent } = require("./sdk/client.cjs");
const client = new PluginLabsClient({ token: process.env.PLUGINLABS_TOKEN });

const saglayici = await new ProviderAgent(client, {
  id: "ornek-uygulama",
  name: "Örnek PluginLabs uygulaması",
  actions: [
    { id: "status", label: "Uygulama durumu", write: false,
      run: async () => ({ ready: true }) },
    { id: "save-draft", label: "Taslak kaydet", write: true,
      run: async (input) => taslakKaydet(input.text) },
  ],
}).start();

// Başka bir istemciden çağır: yazma işlemi masaüstünde onaya gider
await client.invoke("ornek-uygulama", "status", {});
  • write: true olan her işlem tek tek kullanıcı onayına gider.
  • Sağlayıcı kendi girdi doğrulamasını ve yetki denetimini de uygulamalıdır.
  • Bağlanmış olmak, diğer uygulamaların verilerine erişim sağlamaz.

Kaynak paketleri

Veri ve görünüm paketleri .plpack uzantılı JSON dosyalarıdır. Örnek: resources/example.plpack.

  • Türler: asset, template, library, plugin.
  • Kimlik custom- ile başlar; sürüm semantik sürümdür.
  • En fazla 2 MB; ayarlar kısa metin ve onay kutusudur.
  • İçerik veri olarak saklanır; script, HTML ya da kabuk komutu olarak çalıştırılmaz.

Hub kataloğuna ekle

Her PluginLabs uygulaması Hub'dan kurulabilir olmalıdır. Yayın akışı:

  1. Windows taşınabilir EXE'yi herkese açık pluginlabs-dagitim deposunda <katalog-id>-v<sürüm> etiketiyle yayımla.
  2. src/catalog.cjs kaydına sürümü, dosya boyutunu ve SHA-256 özetini yaz.
  3. README'ye güncel, gerçek ekran görüntülerini ekle; Hub'ı yeni katalogla yayımla.
src/catalog.cjs
{
  id: "ornek-uygulama",
  name: "Örnek Uygulama",
  kind: "app",
  version: "0.1.0",
  platform: "win32",
  format: "exe",
  size: 8493056,
  sha256: "<64 karakterlik özet>",
  url: dist("ornek-uygulama", "0.1.0", "OrnekUygulama-0.1.0-portable.exe"),
}

Tasarım sistemi

PluginLabs arayüzleri PluginLabs Advanced tasarım sistemini kullanır: 181 komponent, 6 yüzey teması, 11 ürün aksanı. Sistem bir katmandır; yalnız [data-pl] kapsayıcısında devreye girer ve mevcut stillerinle çakışmaz.

index.html
<!-- Sıra sabittir -->
<link rel="stylesheet" href="pl/pl-tokens.css">
<link rel="stylesheet" href="pl/pl-components.css">
<link rel="stylesheet" href="pl/pl-advanced.css">

<div data-pl data-pl-theme="dark" data-pl-product="leo" lang="tr">
  <button class="pl-btn pl-btn--primary">Eklentiyi kur</button>
</div>

Canlı örnek: aynı komponent, farklı ürün aksanı.

  • Renk, boşluk, köşe ve süre değerleri yalnız var(--pl-…); sabit hex yazma.
  • Her ekranda tek birincil buton; yıkıcı eylemin adı Arşivle, toast'ta Geri al.
  • Her uygulamada Ctrl K komut paleti bulunur; odak halkası asla kaldırılmaz.
  • Türkçe biçimler: 01.11.2026, 1.249,90 ₺, %12.
