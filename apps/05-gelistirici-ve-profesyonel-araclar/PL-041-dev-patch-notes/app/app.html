Git değişikliklerinden kaynak commit bağlantılı sürüm notları üretin

Seçilen git log, commit listesi ya da git diff çıktısını içe alın. Dev Patch Notes değişiklikleri Özellik, Düzeltme, Güvenlik ve Kırıcı Değişiklik başlıklarına ayırır; otomatik commit, push veya yayın yapmaz.

  1. Kaynak commit bağlantıları: Her sürüm notu maddesi kaynak commit SHA ve depo bağlantısıyla eşlenir.
  2. API anahtarı ve sır taraması: Commit mesajlarında veya diff içinde unutulan sk-..., ghp_..., AKIA... anahtarları yakalanır ve maskelenir.
  3. Uydurma teslim iddiası sıfır: Kanıtı olmayan “tüm testler geçti” veya “performansta %X artış” iddiaları otomatik ayıklanır ve engellenir.
  4. Düzenlenebilir Markdown ve Keep a Changelog: Dışa aktarmadan önce her maddeyi düzenleyebilir veya MyMind ile kullanıcı diline çevirebilirsiniz.
