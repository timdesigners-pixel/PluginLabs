Model sağlayıcılarını, maliyetlerini ve yanıtlarını karşılaştırın

Model Switchboard resmi API anahtarıyla tek panelde iki sağlayıcının (OpenAI ve Anthropic) tarihli katalog fiyatlarını, görev başı gerçek maliyet tahminini ve yan yana yanıt değerlendirmesini sunar. Tüketici web hesabı çerezi kullanılmaz; kullanıcı bütçe tavanı aşımı engellenir.

  1. Tarihli model kataloğu: Her modelin 1M girdi/çıktı token fiyatı ve doğrulama tarihi görünür (%100 maliyet görünürlüğü).
  2. Kullanıcı bütçe tavanı: Görev çalıştırılmadan önce tahmini maliyet bütçe tavanıyla karşılaştırılır; tavanı aşan istek engellenir (aşım hedefi: 0).
  3. Yan yana değerlendirme: Aynı görevde iki modelin gecikmesi (ms), token kullanımı, gerçek maliyeti ($) ve rubrik kalite puanı karşılaştırılır.
  4. Kayıtlı testlere bağlı öneri: Görev türüne göre en uygun model, kayıtlı benchmark sonuçlarına bağlanarak önerilir.

    1 · Resmi API anahtarı kasası (OpenAI)

    Yalnız resmi API anahtarı kabul edilir; tüketici web hesabı çerezi (cookie/session) reddedilir. Anahtar Windows kasasında (DPAPI) şifreli saklanır; API faturası sağlayıcı tarafından ayrıca ücretlendirilir.

    2 · Resmi API anahtarı kasası (Anthropic)

    İlk sürüm iki resmi sağlayıcıyı destekler. Tüketici web oturumu çerezleri güvenlik ve sözleşme sınırı gereği engellenir.

    Tüketici çerezi: 0

    Görev türüne göre model önerisi

    Notion yapay zekâ rolü: görev türüne göre model önerir; hız/kalite ölçümünü kayıtlı test sonucuna bağlar.

    Doğrulama ölçütleri

    Notion doğrulama ölçütü: görev başına gerçek maliyet görünürlüğü %100 ve bütçe tavanı aşımı sıfır hedefi.

    Kullanıcı bütçe tavanı (USD)

    Toplam harcama + yeni görev tahmini bu tavanı aşarsa karşılaştırma çalıştırılmaz ve bütçe aşımı engellenir.

    Yapay zekâ öneri motoru (Loopback)

    İsteğe bağlıdır; her istek ayrı onaylanır ve yalnız bu bilgisayara (127.0.0.1 / localhost) gider.

    Dışa aktarma ve gizlilik

    • Her karşılaştırma kaydında girdi/çıktı token sayısı, model birim fiyatı, fiyat doğrulama tarihi ve görev toplam maliyeti görünür (%100 maliyet görünürlüğü).
    • Tüketici web hesabı çerezi kullanılmaz; sağlayıcı API faturası kendi hesabınızdan ayrıca ücretlendirilir.
