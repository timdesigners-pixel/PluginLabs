Mevcut arayüzün renk, yazı ve boşluk sistemini belgeleyin

Seçili sayfadaki computed style JSON, CSS veya HTML örneklerinden renk, tipografi, boşluk ve köşe yarıçapı adaylarını çıkarır; yakın değerleri kümeleyerek token tekrarını azaltır ve onayınızla W3C Design Tokens JSON üretir.

  1. Computed style JSON veya CSS örneklerini yapıştırın, panodan alın ya da .css / .json dosyası seçin.
  2. Yakın renkler (ör. #7c6cff ile #7d6dff) ve sapmalı boşluklar (ör. 15px ile 16px) otomatik kümelenir.
  3. İsteğe bağlı MyMind ile semantik token hiyerarşisi (color.bg.canvas, space.md) önerisi alın.
  4. İlke: Yalnız erişilen sayfa ve hak sahibi olunan tasarımda kullanılır; tasarım kopyalama yerine var olan sistemi belgeler. Dinamik durumlar (hover, focus) ayrıca örneklenir.
